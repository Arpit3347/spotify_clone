# 🎵 Spotify Clone

A responsive **Spotify Web Player Clone** built using HTML, CSS, and JavaScript.
This project recreates the basic Spotify music-player experience with a responsive UI and functional audio controls.

## 🚀 Features

* 🎵 Play and pause songs
* ⏮️ Previous and next song controls
* 🔊 Volume control
* ⏱️ Interactive seek/progress bar
* 🎨 Dynamic song/album background
* 💿 Rotating album/radio image while playing
* 📱 Responsive design for desktop, tablet, and mobile
* 🎶 Automatically loads songs from the songs folder

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub

## ▶️ How to Run

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project in **VS Code**.

3. Run it using **Live Server**.

4. Open the provided localhost URL in your browser.

> Note: Because the project loads songs dynamically, using Live Server is recommended instead of opening `index.html` directly.
